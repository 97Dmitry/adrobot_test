# Небольшая доработка UI/UX

Статус: пользователь разрешил улучшение UI/UX в ограниченном объёме.
Основа: [спецификация функций](../001-keitaro-wrapper/spec.md), принятая в PR #6.

## Проблема и границы

Постоянно раскрытая форма создания занимает первый экран на мобильной ширине.
Редактору не хватает места, действия смешивают русский и английский язык,
а выбор результата нативного datalist с клавиатуры остался неподтверждённым.

Один PR, три изменения:

1. Выбор существующей кампании первым; форма создания в native details,
   изначально закрыта. Боковая колонка уже, редактор просторнее; на мобильном
   экране оба входа компактны и располагаются перед потоками.
2. Компактные строки офферов и единые русские названия действий:
   «Опубликовать», «Отменить», «Удалить», «Вернуть», «Закрепить», «Сохранить»,
   «Снять». Доля, закрепление и архив остаются видимыми; жёлтый — черновик,
   серый — архив, состояния дополнительно обозначаются текстом.
3. Поиск кампаний/офферов показывает результаты внутри страницы с ID и названием.
   ArrowDown/ArrowUp выделяют пункт, Enter выбирает, Escape закрывает список.
   Выбор не отправляет изменение автоматически; числовой ID можно ввести вручную.
   Сохраняются задержка 250 ms, ограничение API и защита от запоздалых ответов.

Нет изменений API, расчёта весов, схемы БД и публикации. Нет новых зависимостей,
страниц, модальных окон, тем, статистики или авторизации. Проверки только на fake
Keitaro; повторные реальные записи для этой доработки не требуются.

## Решение исполнителя

Рассмотрены CSS-правки без изменения формы (не освобождают первый экран),
сворачиваемая форма (выбрана) и модальное создание (добавляет управление фокусом).
Для поиска выбран небольшой общий listbox вместо нового UI-фреймворка.

Цвета сохраняются: white #fff, navy #18384b, blue #126899, slate #526978,
draft #fff4cc, archive #f0f3f5. Системный sans-serif, табличные цифры весов.
Выравнивание слева, без декоративных карточек/метрик и анимаций.

```text
Открыть кампанию       Название кампании + синхронизация
[Поиск] [Загрузить]    Поток / статус
▸ Новая кампания      Оффер | доля | закрепление | действие
                      Сумма           Отменить / Опубликовать
```

## Критерии

- UX1: создание раскрывается клавиатурой/мышью; данные формы и ключ операции
  не теряются при сворачивании, успешное создание сворачивает форму.
- UX2: при 390×844 после открытия кампании её заголовок виден в первом экране;
  при 1440×1000 редактор занимает больше ширины, документ не переполняется.
- UX3: списки читаемы, доступны мышью и клавиатурой, раскрытие/выделение доступны
  assistive technology; Escape/blur закрывают список. Имена вставляются как текст.
- UX4: первый Enter выбирает выделенный результат без Add/создания/Sync;
  отдельное действие или следующий Enter над числовым ID запускает операцию.
- UX5: все существующие сценарии черновика, архива, pin, потери ответа и pending
  остаются рабочими. Во время изменения выбор результата также заблокирован.

Приёмка — существующие Chromium-сценарии плюс проверки UX1–UX4, screenshots
desktop/mobile, Ruff, полный pytest и одно независимое review. После PR — остановка.
