### Итоговое review и исправление

Независимый reviewer воспроизвёл P1: после потери ответа замена страны au→AU
автоматически меняла idempotency key и создавала дубликат. Автор отдельно
воспроизвёл RED для страны и добавленного префикса имени; ещё один RED показал
неявный переход к другой операции после изменения бизнес-параметров.

Исправлено: сравниваются нормализованные параметры, повтор использует прежние
body/key; для иных параметров нужна кнопка «Начать новую операцию». Все три
регрессии GREEN, полный набор **127 passed / 2 skipped**. Повторного независимого
review исправлений не выполнялось. Других подтверждённых значимых findings нет.

Выбор пункта нативного datalist стрелками и Enter в системном popup не подтверждён
headless-проверкой: он не сработал и в контрольном input без обработчика.
Гипотеза о влиянии preventDefault не доказана; тест подтверждает поиск и Enter
при введённом числовом ID. Проверка системного popup вручную остаётся ограничением.
Это историческое ограничение этапа 5; итерация 002 заменяет нативный popup
списком внутри страницы и проверяет ArrowDown/ArrowUp/Enter в Chromium.

Первый CI выявил гонку проверки Remove/Publish: тест считал серую строку
подтверждением публикации, хотя серой она становится уже в черновике. Задержка
PUT 200 ms воспроизвела RED локально. Тест теперь ждёт статус «Опубликован»
перед проверкой Keitaro; задержка оставлена в fake для проверки этого ожидания.
