## Этап 2 — создание кампаний

`uv run --frozen --extra dev pytest tests/test_keitaro.py tests/test_migrations.py tests/test_creator.py tests/test_cli.py -q`
→ **38 passed** (14 основы + 21 создавателя + 3 CLI).
Ruff check и format check файлов этапа проходят. Проверка tracked-файлов
на точное значение локального API-ключа: совпадений нет.

| Критерии | Сценарии и свидетельства |
|---|---|
| AC1.1–1.3 | `tests/test_creator.py`: ISO-коды, нормализация, prefix, отсутствующий оффер/каталог; удалённых записей при ошибках нет |
| AC1.4 | правильные payload, порядок потоков, Google URL, country/accept и оффер 100%; отрицательная readback-проверка лишнего фильтра, landings и null |
| AC1.5 | локальная Campaign и результат с ID/ссылкой; импорт потоков и UI входят в следующие этапы |
| AC1.6 | сбой второго потока оставляет disabled-кампанию с известным ID; потерянный ответ включения сверяется чтением; недоступная сверка имеет статус unknown |

замечания. Оба воспроизведены регрессионными тестами RED → GREEN.
HTTP/UI и межзапросная сериализация не входили в границы этого review.
