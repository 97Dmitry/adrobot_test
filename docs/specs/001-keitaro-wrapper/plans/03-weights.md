# Распределение весов — план реализации

> Исполнитель: `superpowers:executing-plans`. Спецификация: [../spec.md](../spec.md).

**Цель:** AC4.1–AC4.6, стабильное распределение ровно 100%.
**Архитектура:** чистая функция; не читает БД/API и не меняет вход.
**Стек:** Python, pytest, Hypothesis.

## Задачи

- [ ] W1. `tests/test_weights.py`: [], [None], три/четыре None, [25,None,None],
  все закреплены, сумма >100, недостаточный остаток, bool/float/0/101.
  Инварианты: сумма 100, pins сохранены, незакреплённые отличаются ≤1.
  Запуск `uv run pytest tests/test_weights.py -q`: RED → GREEN.
- [ ] W2. `app/weights.py`: `distribute(pins: list[int | None]) -> list[int]`.
  Пустой список даёт []; divmod остатка, лишний 1% первым в списке.
  При недопустимом бюджете — DomainError 422, без частичного результата.

**Выход:** редактор передаёт только активные строки в стабильном порядке;
архивные веса редактор устанавливает в 0 отдельно.
**Приёмка:** VT3; пример 25/38/37; property-based проверки.
